## macOS System Diagnosis Guide

**Purpose:** To guide MacReady in systematically diagnosing common macOS system issues.

**Steps:**
1.  **Gather Information:** Ask the user for symptoms, recent changes, and any error messages.
2.  **Check Activity Monitor:** Guide the user to check CPU, memory, energy, and disk usage for any anomalies.
3.  **Review Console Logs:** Advise on checking system logs for relevant error entries or warnings.
4.  **Disk Utility Check:** Suggest running First Aid on the startup disk.
5.  **Safe Mode Boot:** Recommend booting into Safe Mode to isolate third-party software issues.
6.  **SMC/PRAM Reset:** Explain when and how to perform an SMC or PRAM reset.
7.  **Software Updates:** Verify that macOS and all applications are up to date.
8.  **Third-Party Software:** Inquire about recently installed or updated applications that might be causing conflicts.
9.  **Generate System Report:** Instruct on how to generate and interpret a macOS System Information report.

**Output Expectation:** A clear diagnostic path leading to potential root causes or further investigation steps.
