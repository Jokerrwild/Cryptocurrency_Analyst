## Project Processing Rules

* The Bayesian framework's weighted percentages are dynamic and must be treated as a living system.
* Continuously refine weights based on new data in a feedback loop.
* When outliers in data trigger unexpected outcomes, annotate these events and adjust the weight percentages for that specific information type to improve future analysis.
